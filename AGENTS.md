# AGENTS.md

Guidance for any AI agent working in this repository. Read this file first, then follow the links to the doc you need.

## Project

**Match Day** lets youth league organizers and coaches submit match results and publishes live standings, recent results, and top scorers on a shareable page. Full description: [product-spec.md](product-spec.md).

## Stack

- Frontend: React + Vite (`frontend/`)
- Backend: FastAPI + SQLAlchemy (`backend/`); SQLite by default, Postgres through `DATABASE_URL`
- Tests: `cd backend && python -m pytest`
- Run everything locally: `docker compose up --build` (app at http://localhost:8080)
- CI/CD: GitHub Actions (`.github/workflows/ci.yml` and `deploy.yml`), hosted on Render
- API reference: generated by FastAPI at `/docs` on any running instance

## Rules for all agents

1. Work from a GitHub issue. Reference its number in your branch name, commits, and PR (`#12`).
2. The acceptance criteria on the issue are the definition of done. Do not expand scope.
3. Never commit secrets, submit tokens, deploy hook URLs, or personal data.
4. Every change ships with tests. Run the full test command before opening a PR.
5. Do not push to `main`. Open a PR; CI must pass.
6. Production deploys are manual and require human approval. Agents never approve their own deploys.
7. If requirements are unclear, comment on the issue instead of guessing.
